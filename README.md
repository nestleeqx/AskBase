# AskBase — Telegram-бот, который отвечает по базе знаний

Бот отвечает клиентам компании строго по её документам: прайсу, списку врачей, ответам на частые вопросы и правилам записи. Если ответа в документах нет, честно говорит «Уточню у администратора» и передаёт вопрос человеку. Владелец загружает документы и смотрит диалоги в веб-админке.

**Демо-легенда:** стоматологическая клиника «Белая линия». Клиника, врачи, цены и адрес вымышлены.

> Проект в разработке. Описание, скриншоты и инструкция по запуску появятся по мере готовности.

## Демо-база знаний

`backend/app/seed/` — документы клиники и тестовый набор вопросов:

| Документ | Формат | Файл |
| --- | --- | --- |
| Прайс-лист | PDF | `docs/prajs-list.pdf` |
| Врачи и график работы | DOCX | `docs/vrachi-i-grafik.docx` |
| Частые вопросы: подготовка, гарантии, оплата | TXT | `docs/faq.txt` |
| Правила записи | страница сайта | `docs/pravila-zapisi.html` |

Исходные тексты PDF, DOCX и страницы лежат в `source/` (Markdown), файлы собирает `backend/scripts/build_demo_docs.py`.

`eval-questions.json` — 20 вопросов по документам с эталонными фактами и документом-источником и 5 вопросов вне базы, на которые бот должен передать вопрос администратору. Набор зафиксирован до настройки промптов: по нему считается точность ответов.
